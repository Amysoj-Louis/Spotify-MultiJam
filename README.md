# Spotify MultiJam

An unofficial Python script for concurrent remote playback control across multiple Spotify accounts and connected devices.

## Features
- Multi-Account Control: Synchronize or differentiate playback across different users.
- Remote Commands: Play, pause, resume, and search programmatically.
- Device Management: Target specific Spotify Connect devices.
