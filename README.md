# Spotify MultiJam - Multi-Account Playback Controller

A specialized Python utility designed for concurrent remote playback control across multiple Spotify accounts and connected devices using the **Spotify Web API**.

## 🎵 Project Overview
**Spotify MultiJam** is a technical solution for synchronizing or differentiating music playback across a network of Spotify accounts. It leverages the **Spotify Connect** protocol to target specific devices, allowing users to programmatically manage play, pause, resume, and search functions. The project is provided as an interactive Jupyter Notebook, ideal for developers looking to automate multi-device audio environments.

## ✨ Key Features
- **Multi-Account Orchestration**: Command and control multiple independent Spotify accounts from a single execution context.
- **Precision Device Targeting**: Identify and interact with specific Spotify Connect devices (speakers, TVs, apps) across the network.
- **Programmatic Playback Control**: High-fidelity control over playback states including volume, positioning, and queue management.
- **Automated Search & Queue**: Robust logic for searching the Spotify catalog and dynamically building queues.
- **Secure Authentication**: OAuth 2.0 handled integration for multiple user sessions.

## 🛠️ Tech Stack
- **Language**: Python 3.10
- **API Integration**: Spotify Web API
- **Environment**: Jupyter Notebook
- **Authentication**: OAuth 2.0 Authorization Flow
